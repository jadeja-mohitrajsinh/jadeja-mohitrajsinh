## About Me

I work on AI, security, and system design — focusing on building reliable systems instead of flashy prototypes.
My interest is in how software scales, how it breaks, and how to make it harder to break.

### What I Care About

* **Clean, understandable code**
* **Security-first architecture**
* **Automating what humans shouldn’t do manually**
* **Systems that are maintainable, not just “working for now”**

### Technical Focus Areas

* **Backend & APIs:** Python, FastAPI, Node.js, Express.js
* **Frontend:** JavaScript, TypeScript, React
* **Databases:** MongoDB, Firebase (Firestore)
* **Infrastructure & Deployment:** Linux, Docker, Kubernetes, AWS, GCP
* **Version Control & Collaboration:** Git & GitHub

### How I Work

* I prefer clarity over cleverness.
* I document decisions as they happen.
* I don’t rush features at the cost of stability.
* I’d rather build something small and strong than big and fragile.

### Currently

* Strengthening automation and cloud security workflows
* Improving reliability of microservice-style deployments
